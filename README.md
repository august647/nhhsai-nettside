# Arbeidsfiler for nyhetsutgaver

Mellomresultater fra den ukentlige nyhetsjobben, en mappe per uke (`uke-<uke>-<år>`). Jobben leser dem ved oppstart og hopper over fasene som allerede er ferdige. Det betyr at en kjøring som stoppes av bruksgrensen i abonnementet, kan fortsette der den slapp. Ingenting her publiseres på nettsiden.
